## Suggested verification once the actual source is present
1. Open the project in a compatible NI LabVIEW 2020 environment.
2. Follow its *actual supplied* source README for the entry VI and demo credentials.
3. Verify role permissions and 3-attempt / 30-second lockout.
4. Check configured thresholds and start permissives.
5. Test RUNNING operation, warning/trip behavior and reset restrictions.
6. Review timestamped audit events and compare the manual acceptance matrix.

No particular VI filename, hidden code architecture, model constants or device dependencies are assumed without inspecting the final package.
